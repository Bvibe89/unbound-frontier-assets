# Desert Terrain Material Library

First terrain material set for the desert planet. Five seamless materials
designed as one family, for blending across Godot terrain.

Blender source: `Blender Source/Terrain_Materials_Desert.blend`

## Contents

| Material | Intended use |
| --- | --- |
| `Terrain_DesertSand` | Primary open-world surface |
| `Terrain_HardpackedDirt` | Settlements, camps, frequently travelled ground |
| `Terrain_RockyDesert` | Cliffs, rocky regions, ruins, creature areas |
| `Terrain_CrackedEarth` | Dried basins, lairs, environmental storytelling |
| `Terrain_FrontierPath` | Roads, settlement paths, checkpoint approaches |

Each has three maps:

- `*_BaseColor_1k.png` — 1024x1024, 8-bit RGB, **sRGB**
- `*_Normal_512.png` — 512x512, 8-bit RGB, **non-color**
- `*_Roughness_512.png` — 512x512, 8-bit grayscale, **non-color**

No metallic maps. Natural terrain is non-metal; set metallic to 0.

## Palette provenance

The palette was measured from the approved prop GLBs (Generator, Light Post,
Locker, Mission Terminal, Openable Crate, Raider Bone Totem, Raider gate,
Raider Territory Mark, Raider Watch Tower) rather than chosen by eye.

Those props share a warm hue axis at roughly **R : G : B = 1.00 : 0.83 : 0.65**
(hue ~31 degrees). Every terrain material uses that same hue axis, so the whole
set is guaranteed to sit in the pack's family.

Relationship to the props, by design:

| | props (measured) | terrain |
| --- | --- | --- |
| value | 0.20 – 0.43 | 0.52 – 0.69 (brighter) |
| saturation | 0.07 – 0.43 | 0.22 – 0.30 (quieter) |
| roughness | 0.51 – 0.66 | 0.75 – 0.87 (drier) |

Terrain is brighter so dark props read against it, and less saturated so props
stay the visually interesting elements.

## Godot setup

- Base color: import as sRGB (default).
- Normal and roughness: **must** be flagged non-color / linear, or roughness
  will be wrong and normals will be too strong.
- Normal maps use the **OpenGL / glTF +Y (green up)** convention, matching the
  pack's existing GLB assets. No green-channel flip needed.
- `normal_scale` **1.0**. Restraint is already baked into the maps
  (slope-calibrated, see below) — do not raise it.
- Roughness: use the map directly, roughness multiplier 1.0. Metallic 0.
- Recommended world tile: **4 m** (usable 3–6 m). If your terrain mesh UVs are
  1.0 per metre, set `uv1_scale` to `0.25` for a 4 m tile.

At a 4 m tile the embedded stones read ~15–26 cm and the dry-earth plates
~57 cm, which is why 4 m is the recommendation.

## Regenerating / tweaking

`_generate_desert_terrain.py` is the editable source for these textures. Run it
inside Blender's Python (it needs numpy; plain system Python here does not have
it):

```python
ns = {"__file__": r"<path to the script>", "__name__": "gen"}
exec(open(ns["__file__"]).read(), ns)
ns["main"](qa_dir=r"<somewhere for QA sheets>")
```

Seeds are fixed, so a re-run reproduces these exact files. It also writes two QA
sheets: `qa_tiled.png` (2x2 tiling / seam check) and `qa_detail.png` (1:1 detail
check).

Notes for anyone editing it:

- Tiling is seamless **by construction**, not by edge-blending: all noise is
  generated by filtering white noise in the frequency domain, which is
  inherently periodic, and Voronoi cell lookups wrap. Coordinate warps are
  periodic and taken modulo 1, which preserves that.
- The noise spectrum is a **power law**, not a gaussian low-pass. A narrow
  gaussian band has a dominant wavelength and produces a visible woven /
  herringbone artifact.
- A domain warp must use **smooth** noise (`snoise`). A power-law field used as
  a warp pinches Voronoi cells into squiggly loops.
- Normal strength is auto-calibrated per material so the 99th-percentile slope
  hits a target angle (sand 7 deg, path 6 deg, dirt 9 deg, cracked 14 deg,
  rocky 16 deg). Change the target angle, not a raw multiplier.

## Known limitations

- **No baked path crown.** `Terrain_FrontierPath` is uniformly compacted with
  faint directional wear. A literal smoother centre strip was deliberately left
  out: baked into a tiling texture it repeats as visible stripes and fights the
  terrain splatmap. Get the crown from terrain blend weights, and tracks or
  footprints from decals.
- **Rocky stone clusters repeat** if a single tile is visibly repeated more than
  about 3x3 on screen. Break it up with terrain blending or scattered rock
  props rather than relying on the texture alone.
- No ambient-occlusion or height/displacement maps. Add them only if the
  terrain shader actually uses them.
- Base color carries a subtle contact-shadow ring around the rocky stones to
  embed them. If you later add a real AO map, that ring is slightly redundant.
